# Dallas Home Improvement Cleaning Services

The website at https://dallashomeimprovementexperts.com — plain HTML, CSS and JavaScript, no build step.

- `index.html` home page; one `.html` file per service page (served without the `.html`, e.g. `/window-cleaning`)
- `css/style.css`, `js/main.js`, `images/`
- `sitemap.xml`, `robots.txt`

Hosted on Netlify (project `resonant-kulfi-e58012`). Pushing to `main` publishes the live site.

This repository was started from a copy of the live site as of November 2026 (previously uploaded with Netlify Drop).
